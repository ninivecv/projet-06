# Journal d’utilisation de l’intelligence artificielle

## Usage 1 — Organisation du projet

Gemini a été utilisé pour proposer une répartition des tâches entre les membres de l’équipe ainsi qu’une structure générale pour le fichier `README.md`. Les propositions ont servi de point de départ et ont été adaptées au projet par l’équipe.

## Usage 2 — Reformulation de phrases

Antidote, un outil d’aide à la rédaction intégré au logiciel utilisé par l’équipe, a servi à reformuler certaines phrases afin d’en améliorer la clarté et la formulation.


## Usage 3 - Structure partielle du code pour les graphiques de l'analyse exploratoire

L’IA a aidé à structurer le code R pour vérifier les variables, résumer les mesures cliniques et les habitudes de vie ainsi que de produire les tableaux et graphiques de l’analyse exploratoire.

## Usage 4 - Structure partielle du code pour les graphiques des k-moyennes

L’IA a aidé à structurer le squelette du code R pour produire les tableaux et graphiques des k-moyennes.
